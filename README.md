# LIFE v1.2

Следующий этап LIFE: русское Liquid Glass приложение на Android.

## Добавлено
- живой главный экран LIFE;
- живые часы;
- быстрые действия: вода, шаги, еда, расход, учёба, спорт, задача;
- сохранение быстрых данных локально на телефоне;
- дневные индикаторы воды, шагов, учёбы и задач;
- базовый анализ дня;
- подготовка Android-моста для уведомлений и Health Connect;
- сборка APK через GitHub Actions.

## Важно
Подсчёт калорий по еде пока является подготовкой интерфейса: настоящий AI-анализ текста/фото требует безопасного backend/API. Никаких API-ключей в APK.
